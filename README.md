# AE2 - Manejo de archivos CSV, JSON y TXT

## Objetivo
Importar, modificar y guardar archivos CSV y JSON mediante clases de Python y generar un resumen TXT desde Jupyter Notebook.

## Estructura
- `manejador_csv.py`: manejo de archivos CSV.
- `manejador_json.py`: manejo de archivos JSON.
- `generador_resumen_txt.py`: generación del resumen.
- `AE2.ipynb`: coordinación y ejecución del proceso.
- `datos/`: archivos originales y modificados.

## Ejecución
Abrir `AE2.ipynb` en Jupyter Notebook y ejecutar las celdas en orden.
